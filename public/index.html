People

Sign in to read the context in the browser — the overview, every file, and the audit of what it does not say yet.

Nothing is stored on this server: your repository and your keys travel with each request — in plaintext while it is processed — and are gone when it ends. Revoke access any time by uninstalling the App. Rather run it yourself? The same server is MIT licensed: npx orgspec.

Your context repository

Any GitHub repository, private is fine, that follows the Org Context Spec — a handful of Markdown files. No repository yet? Connect an empty one and ask your AI to set it up: it gets the starter templates from the server, interviews you about what you know, and seeds the repository through the same review loop that later maintains it.

Alternative: connect with a fine-grained access token

On GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.

  1. Repository access: Only select repositories — your context repository alone, so the token can never touch anything else.
  2. Repository permissions: Contents read and write, Pull requests read and write. Both are needed — with Contents alone a proposal is committed to a branch but the pull request fails.
